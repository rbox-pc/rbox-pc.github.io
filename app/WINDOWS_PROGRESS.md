# RetroBox Windows development baseline

Imported from RetroBox_v6_Atari_Memory_Fix_Source(1).zip.

Added keyboard controls: arrows, Z/X/A/S/Q/W, Enter, right Shift.
Input clears when focus leaves the player to prevent stuck buttons.
Replaced stale Flutter counter test (referenced nonexistent MyApp) with a player startup failure test.

This is an incomplete prototype. Audio, native USB/Bluetooth gamepads,
save progress, BIOS handling, cheats, Turbify licensing and Microsoft Store
billing are still pending. Do not distribute as a finished paid app.
Required commercial design: four plans (monthly/annual, with/without promo);
7-day promo trial controlled by Turbify. No 30-day trial.
NES was previously reported working by the user; other consoles require real Windows tests.
No ROMs, BIOS, DLLs, generated build caches or credentials are included.
The existing download page remains intact on main.
